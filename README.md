### ⬛ The Philosophy
Věřím v **extrémní minimalismus** a maximální výkon. Moje práce je definována termínem "Black Edition" – čistý kód, hluboká černá a žádný zbytečný šum.

- 🌑 **Dark Mode First**: PWA aplikace optimalizované pro OLED displeje.
- 📐 **Wireframe Precision**: Každý pixel má své místo.
- ⚡ **Zero-Latency**: Zaměřeno na okamžitou odezvu a offline funkcionalitu.
